# 杖剑传说 · KOC 内容机会决策与复盘工作台 V3

## 定位
围绕游戏项目实际营销任务，整合候选热点、历史案例、创作者能力和执行数据，完成：
**发现机会 → 判断是否值得做 → 形成内容方向 → 匹配创作者 → 跟进执行 → 自动生成周期复盘 → 沉淀可复用经验 → 反哺下一周期推荐**

不做全网资讯抓取和舆情监测，自动/导入信息仅作为候选，核心价值是把信息转化为可执行的内容机会。

## 快速启动
```
双击 start.bat
本机访问   http://localhost:4567
团队访问   http://<本机内网IP>:4567   （启动窗口会显示）
```
数据集中存储在服务器端 SQLite（data/zj_koc_v3.dat），团队成员浏览器访问即可协作，无需各自安装。

## Docker 部署
适合服务器部署和后续升级。代码放 Git，数据库通过 volume 挂载保留。

首次部署：
```bash
cp .env.example .env
docker compose up -d --build
```

访问：
```text
http://服务器IP:4567
```

后续升级：
```bash
git pull
docker compose up -d --build
```

如果使用 GitHub Actions 打好的镜像：
```bash
docker compose -f docker-compose.ghcr.yml pull
docker compose -f docker-compose.ghcr.yml up -d
```

数据库默认挂载在：
```text
server/data/zj_koc_v3.dat
```

注意：不要把 `.env`、`server/data/*.dat`、`node_modules/`、`dist/` 提交到 Git。

## 六个一级页面
| 页面 | 职责 |
|------|------|
| 今日工作（默认首页） | 候选热点智能排序推荐、待判断/进行中机会、我的待办、进行中任务 |
| 营销任务 | 项目背景、营销目标、机会判断标准、关键词（驱动推荐与AI评估） |
| 机会中心 | 机会判断（AI+规则双评分）→ 内容方向 → 创作者匹配 → 执行跟进，全程留痕 |
| 案例库 | 历史内容表现（播放/激活/ROI/成败要点），为判断和匹配提供依据 |
| 创作者库 | 合作能力档案（擅长类型/均播/历史激活率/历史ROI/报价） |
| 周期复盘 | 按周期自动汇总数据生成AI复盘 → 确认 → 沉淀经验 → 反哺推荐 |

数据导入（Excel/CSV）、AI分析、经验沉淀均嵌入对应页面，不占一级导航。

## 推荐与评分逻辑
- **规则引擎（兜底，永远可用）**：热度趋势(25) + 任务关键词匹配(30) + 历史案例题材表现(25) + 沉淀经验加降权(±20)
- **AI评估（OpenAI兼容中转站/Gemini）**：结合营销任务判断标准、相关案例、沉淀经验、创作者数据给出评分、分析、内容方向和创作者推荐；含 503/429 指数退避重试，失败自动降级为规则打分
- 评估维度对齐团队核心指标：高消费潜力、播放量、首日激活转化率、7日付费ROI

## 后台自动任务
- 服务启动后会开启每日自动任务，默认每天 **07:00（Asia/Shanghai）** 执行一次。
- 自动任务会抓取今日热点和游戏快讯；热点抓取完成后立即生成 AI 推荐分析，并写入数据库快照。
- 在左下角「系统设置」→「后台自动任务」可以查看运行状态、调整时间、手动立即执行。
- 环境变量可配置：`AUTO_TASK_ENABLED=1`、`AUTO_TASK_TIME=07:00`、`AUTO_TASK_BOOTSTRAP=1`。

## 首次使用
1. 系统内置一套《杖剑传说》演示数据，可先熟悉全流程
2. 正式使用前：左下角「系统设置」→ 清空全部数据
3. 在「系统设置」确认 AI 配置（中转站或 Gemini），点击「测试AI连通性」
4. 每位成员首次打开时输入自己的名字（用于操作留痕和待办分配）
